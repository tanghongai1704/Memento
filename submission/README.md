# Submission assets

Thư mục này tập trung artifact dùng khi nộp và trình bày project. Các file tại đây không tham gia vào Android build.

## Slide

Đặt bản PDF cuối cùng tại:

```text
submission/slides/Memento_Tech_Fresher_2026.pdf
```

Xem hướng dẫn tại [submission/slides](slides/README.md).

## Demo

**Video demo:** _Chưa cập nhật liên kết._

Trước khi nộp, thay dòng trên bằng URL có quyền xem công khai hoặc quyền xem dành cho hội đồng. Nên mở link trong cửa sổ ẩn danh để kiểm tra quyền truy cập.

## Checklist trước khi nộp

- PDF mở được và sử dụng đúng phiên bản slide cuối.
- Video demo phát được mà không yêu cầu tài khoản cá nhân.
- README trỏ đúng đến thư mục submission.
- Không đưa credential, Firebase token hoặc dữ liệu người dùng thật vào slide/video.
- Tên project và thuật ngữ **Private Stories** thống nhất giữa README, slide và demo.
